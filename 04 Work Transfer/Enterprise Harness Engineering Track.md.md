# Enterprise Harness Engineering Track

## Purpose

Provide a portable Harness Engineering methodology that can be
applied inside the enterprise environment without transferring
private enterprise information into the public project.

## Known Environment

- PMB is available internally.
- ACR is not currently deployed internally.
- Independent code review is an established requirement.
- Claude Code and Cursor are primary development agents.
- Codex is available as an alternative/fallback.
- LiteLLM is available.
- Enterprise ChatGPT has access to organization-specific knowledge.
- Source repositories are private.

## Observed Problem

Self-review by the implementation agent has demonstrated lower
defect discovery than review performed from an independent context.

## Boundary

No proprietary code, architecture, prompts, configuration,
credentials, or organization-specific information will be stored
in this public repository.

The public project will produce methodology and assessment
templates.

Enterprise-specific analysis will occur inside the approved
enterprise environment.
