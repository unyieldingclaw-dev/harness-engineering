# Harness Engineering

## Mission

Harness Engineering is the discipline of designing, auditing, and optimizing the systems surrounding AI models—including context, memory, instructions, skills, tools, governance, and orchestration—to maximize capability while minimizing persistent cognitive load.

---

## Why this project exists

Modern AI development often accumulates prompts, memories, instructions, rules, and tooling without an engineering framework to evaluate them.

Harness Engineering seeks to establish that framework.

---

## Vision

Develop a portable, evidence-driven discipline that can be applied to any AI ecosystem—not just PMB or ACR.

Reference implementations include:

- Personal Memory Bank (PMB)
- AI Code Review Agent (ACR)

Future implementations may include:
- Claude Code
- Codex
- Cursor
- Enterprise AI platforms

---

## Current Goal

Build the foundations before building the tools.
