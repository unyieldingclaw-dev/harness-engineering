# Harness Engineering — Approved branding

The approved HE identity is the gear, three-layer engineering stack and three connected inspection nodes, in dark navy and electric blue/cyan. Full display name: **Harness Engineering**. Tagline: **Investigate · Validate · Improve**.

## Source fidelity

- `approved-concept-original.png` is an **exact crop** of the user-approved two-logo artwork, and `logo-1024.png` is its resized export. This is the canonical approved visual.
- `icon-{32,64,128,256,512,1024}.png` are raster crops of that approved art, sized for avatars and thumbnails (navy background intentionally preserved).
- `social-preview-1280x640.png` is a layout adapted from the same exact art; this is **not** the automatic GitHub setting.
- `icon.svg`, `icon-small.svg`, `logo.svg`, `logo-transparent.svg`, `icon-monochrome-light.svg`, `icon-monochrome-dark.svg`, and `social-preview.svg` are **genuine hand-redrawn vector adaptations**. They are not pixel-identical traces and should not silently replace the canonical approved raster where fidelity matters.
- `logo-transparent-1024.png` is rendered from the vector adaptation; it is not an alpha-extracted version of the approved raster.

## Use

Use `logo-1024.png` in the repository README to preserve the approved look. Prefer `icon.svg` for scalable illustration when the vector simplification is acceptable. Use the `social-preview-1280x640.png` file when setting the GitHub Social Preview manually via the repository Settings UI.

Palette: background navy `#020B22`; blue `#086BFF`; cyan `#05ECF7`; mint `#00E8C4`; white `#F9FCFF`.

No project runtime, policies, framework, CI, build process, or research scope is changed by branding assets.
